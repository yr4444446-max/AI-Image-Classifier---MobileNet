Aim:
Create and deploy a sample AI model using a cloud-based approach, built with HTML, CSS and JavaScript, hosted live on GitHub Pages.

Project:
An AI Image Classifier. Upload a photo or use your webcam, and a pretrained MobileNet model (loaded live from Google's cloud-hosted TensorFlow.js model hub) identifies what's in the image with a confidence score.

How It Works:
1. Page loads and fetches the MobileNet model from the cloud
2. User uploads an image or turns on the webcam
3. The model classifies the image directly in the browser
4. Top predictions are shown with confidence percentages

Tech Stack:
HTML, CSS, JavaScript, TensorFlow.js (MobileNet)

Deployment:
Hosted for free on GitHub Pages - no backend, no server, no API key required. The model runs entirely client-side in the browser.
